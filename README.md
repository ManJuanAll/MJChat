# MJChat

MJChat —— 一个基于 Supabase 实时数据库的极简、安全、功能丰富的 Web 聊天室。

无需安装，开箱即用，支持图片/文件/语音/链接/文字特效，并内置基础防护和友好的交互体验。

---

## 特性

### · 实时消息

    基于 Supabase Realtime 和 PostgreSQL 的 postgres_changes，消息即时同步，无刷新。

### · 多媒体支持

  · 图片上传（自动压缩，存储至 Supabase Storage）

  · 文件上传（最大 10MB）

  · 语音消息（录音并上传，支持播放控制）

  · 链接分享（自定义显示文字）

### · 文字特效

    选中文字后可快速应用
    
    粗体、斜体、<u>下划线</u>、<s>删除线</s>，并自动识别 @用户名 加粗显示。

### · 用户交互

  · 长按头像 → 自动 @ 对方（插入输入框）

  · 双击头像 → 发送“拍一拍”系统消息（冷却 1 分钟）

  · 长按/右键消息气泡 → 弹出上下文菜单

### · 上下文菜单（长按或右键）

  · 图片：保存图片、删除

  · 链接/文件：在浏览器中打开、复制文字/下载文件、删除

  · 纯文本：复制文字、删除

  · 回复：快速引用回复（输入框自动填入 “回复 @用户名：”）

### · 移动端优化

    对于触摸，长按等操作的原生支持。

### · UI设计

    深色主题，符合 MD 规范，适配移动端和桌面端。
